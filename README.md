# ai-flap-flap
Dit was een kort project tussen twee grote project in.

In een korte periode mochten wij een project zoveel mogelijk met AI maken. In verband met jeugdsentiment hebben wij gekozen om het spel "Flappy Bird" na te maken.
Alhoewel wij een paar dingen moesten aanpassen voor usability, is, naast een paar afbeeldingen, alles inderdaad gegenereerd met AI.

Met dit project hebben we meer geleerd over de mogelijkheden en reikbreedte van ai.
